คู่มือยื่นขอ TikTok App Audit ให้ผ่านในรอบเดียว (Step-by-Step)

หน้าเว็บ ClipFlow Creator Studio นี้ถูกออกแบบให้มีปุ่มและเงื่อนไขครบทั้ง 5 ข้อตามกฎ TikTok Content Sharing Guidelines ทุกประการ

ขั้นตอนที่ 1: นำไฟล์เว็บนี้ขึ้น GitHub Pages (ฟรี 2 นาที)
  1. สร้าง Repository ใหม่แบบ Public บน GitHub ชื่อเช่น clipflow-studio
  2. อัปโหลดไฟล์เว็บนี้โดยเปลี่ยนชื่อเป็น index.html
  3. ไปที่เมนู Settings → Pages เลือก Branch main แล้วกด Save
  4. คุณจะได้ลิงก์เว็บไซต์จริง เช่น https://georafap.github.io/clipflow-studio/ สำหรับกรอกในฟอร์มของ TikTok!
ขั้นตอนที่ 2: กรอกข้อมูลแอปใน TikTok Developer Portal
  • App Name: ClipFlow Creator Studio
  • Category: Video / Photo Editing & Creation
  • Web/Desktop URL: https://georafap.github.io/clipflow-studio/
  • Terms of Service URL: https://georafap.github.io/clipflow-studio/#terms
  • Privacy Policy URL: https://georafap.github.io/clipflow-studio/#privacy
  • Products & Scopes: เพิ่ม Login Kit (user.info.basic) และ Content Posting API (video.publish, video.upload)
ข้อความภาษาอังกฤษสำหรับช่อง "Explain how your app uses Login Kit and Content Posting API" (กดคัดลอกไปวางได้เลย):

ClipFlow Creator Studio is a web-based video creation and publishing tool for independent content creators. Creators sign in with their TikTok account via TikTok Login Kit (user.info.basic), preview their edited 9:16 vertical video, review their creator profile info queried via /v2/post/publish/creator_info/query/, manually choose their privacy status, configure interaction settings (Comment, Duet, Stitch), disclose commercial content if applicable, and publish directly to their TikTok profile via the Content Posting API (video.publish).

ขั้นตอนที่ 3: วิธีอัดคลิปหน้าจอ (Screen Recording ~45 วินาที) ส่งให้ TikTok ตรวจ

เปิดแท็บ Creator Studio (UX Demo) ด้านบน แล้วอัดคลิปหน้าจอตามลำดับนี้เพื่อให้กรรมการ TikTok เห็นครบทุกข้อ:

  1. กดปุ่ม Continue with TikTok เพื่อแสดงการเชื่อมต่อบัญชีและแสดงชื่อช่อง (@AuraSpaceStudioUs)
  2. กดเลือกไฟล์วิดีโอ .mp4 จากในเครื่อง (หรือกด Animate Preview) เพื่อโชว์ตัวอย่างวิดีโอ 9:16 ด้านซ้าย
  3. พิมพ์แก้ไขข้อความในช่อง Title / Caption & Hashtags
  4. กดเปิด Dropdown Who can view this video (Privacy Status) แล้วเลือก Public to everyone
  5. กดติ๊กถูกที่ Allow Comment, Allow Duet, Allow Stitch
  6. กดเปิดสวิตช์ Disclose video content (Commercial Content) แล้วลองติ๊กถูกที่ Your brand และ Branded content เพื่อให้เห็นข้อความแจ้งเตือนตามกฎของ TikTok (จากนั้นจะเปิดไว้หรือปิดก็ได้)
  7. กดติ๊กถูกที่ช่อง By posting, you agree to... แล้วกดปุ่ม Publish to TikTok จนแถบสถานะขึ้น PUBLISH_COMPLETE เป็นอันจบคลิป!
